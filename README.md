# Jemand, man und Co.

Неопределённые местоимения в немецком (man, jemand, jeder, einer, alle, beide, einige, viele, mehrere, wenige): объяснение по-человечески, анимации по шагам, шкала неопределённости со скроллом, озвучка, тест и тренажёр + платформа Stellas A0–C1. Mobile-first, без зависимостей.

**Сайт:** https://stellasdeutsch-dev.github.io/indefinitpronomen/
